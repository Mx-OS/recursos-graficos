======================================
Fondos de Pantalla de MxOS (Wallpapers)
======================================

Este directorio contiene las ilustraciones vectoriales y composiciones oficiales para fondos de pantalla del sistema operativo MxOS y materiales de escritorio.

Fondos Disponibles
==================

* ``propuesta_01-desierto-fondo-azul.svg``: Composición panorámica estilizada de paisaje desértico con cactáceas y tonalidades nocturnas/azules.

Exportación a PNG
=================

Para compilar los fondos de pantalla a resolución QHD (2560x1440):

.. code-block:: bash

   make

Los archivos resultantes se generarán dentro de la carpeta ``output/``.

Para limpiar los archivos temporales:

.. code-block:: bash

   make clean
